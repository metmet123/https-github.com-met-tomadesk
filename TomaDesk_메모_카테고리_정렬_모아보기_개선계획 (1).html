TomaDesk메모 편집공개 앱 UI 조사 포함

메모 카테고리·정렬·모아보기 개선 계획

기존 계층형 메모를 유지하면서 카테고리 지정 → 필터 → 정렬 → 카테고리별 모아보기를 추가하는 계획이다.

핵심 원칙: 카테고리는 메모의 실제 위치를 바꾸지 않는 별도 메타데이터이며, 보기/정렬은 데이터 자체와 분리한다.

01. 현재 TomaDesk 화면

현재 구조에서 유지할 것
부모·하위 메모 트리, 검색, 최근 메모, 리치 편집, 알림·D-Day 연결은 그대로 유지한다. 카테고리는 이 구조를 대체하지 않는다.
  • 서로 다른 부모 아래의 메모를 업무/개발/자료 같은 주제로 한 번에 모아보기 어렵다.
  • 카테고리 필터·정렬·그룹화가 없고, 메모 목록 정렬은 아직 미정 상태다.
  • 기존 메모가 많으므로 다중 선택 일괄 카테고리 지정이 필요하다.

02. 공개 앱 실제 기능 화면 조사

Notion — View / Filter / Sort / Group

관찰: 같은 데이터에 여러 보기를 만들고, 보기마다 필터·정렬·그룹 설정을 별도로 둔다.

TomaDesk 적용: 기본 트리 보기와 카테고리 모아보기를 별도 보기로 분리한다.

출처: https://www.notion.com/help/views-filters-and-sorts

Apple Notes — Tags / Smart Folders

관찰: 태그는 기존 폴더와 별개이며 Smart Folder는 메모를 실제 이동시키지 않고 조건에 맞는 메모를 모은다.

TomaDesk 적용: 부모·하위 계층은 보존하고 카테고리 보기는 가상 모아보기로 만든다.

기능: Apple Support · 화면: MacRumors

Evernote — 통합 필터 패널

관찰: Tags, 위치, 생성일, 수정일 등을 같은 필터 패널에서 조합한다.

TomaDesk 적용: 우선 검색 + 카테고리 필터를 결합하고, 이후 D-Day/최근 수정 조건을 확장할 수 있게 한다.

출처: https://help.evernote.com/hc/en-us/articles/360050105293-Filter-your-notes-list

Obsidian Bases — 보기별 필터·정렬

관찰: 보기별로 필터·정렬을 저장하고 복잡한 AND/OR 조건도 구성할 수 있다.

TomaDesk 적용: MVP는 단순 필터로 제한하되 향후 저장된 보기로 확장 가능한 구조로 둔다.

기능: Obsidian Help · 화면: Obsidian Forum

05. 정보 구조와 규칙

메모
├─ id
├─ parent_id
├─ title / body
├─ category_id      ← 신규, NULL 허용
├─ modified_at
├─ alarm / dday
└─ 기타 기존 속성

카테고리
├─ id
├─ name
├─ color
└─ sort_order
MVP 권장: 메모당 카테고리 1개. 다중 태그는 실제 사용 필요성이 확인된 뒤 별도 기능으로 추가한다.
  1. 검색과 카테고리 필터는 AND 조건.
  2. 정렬은 화면 표시 순서만 바꾸며 기존 수동 순서와 부모 관계를 수정하지 않음.
  3. 카테고리 이름 변경은 내부 ID 연결을 유지.
  4. 카테고리 삭제 시 메모는 삭제하지 않고 `미지정`으로 변경.
  5. 휴지통 복원·백업 복원 시 카테고리 값도 보존.
  6. 좁은 창에서는 `보기/정렬`을 한 메뉴로 합치는 반응형 배치 허용.

06. 개발 순서

1
카테고리 데이터 + 기본 지정
테이블/마이그레이션, 편집 영역 카테고리 칩, 관리창. 기존 메모는 미지정.
2
필터·정렬 + 일괄 지정
검색과 결합, 최근 수정/제목 정렬, 다중 선택 카테고리 지정, 상태 기억.
3
카테고리별 모아보기
그룹 헤더, 접기/펼치기, 평면 목록, 원래 부모 경로, 미지정 그룹.
4
사용 후 확장
저장된 보기, D-Day/최근 수정 조건, AND/OR, 다중 태그.

07. 완료 기준

  • 기존 DB 자동 마이그레이션 후 메모/계층/휴지통/알림/D-Day가 그대로 동작.
  • 새·기존 메모 카테고리 지정 및 여러 메모 일괄 지정 가능.
  • 검색 + 카테고리 필터 + 정렬 동시 사용 가능.
  • 기본 트리와 카테고리 모아보기 전환 가능.
  • 카테고리 변경/삭제 후 고아 참조 없음.
  • Windows 100%·125%·150% 배율과 좁은 창에서 가로 스크롤 없이 핵심 기능 유지.

이번 범위에서 다중 태그, AI 자동 분류, 복잡한 저장 검색, 기존 계층의 카테고리 변환, EXE 생성은 제외 권장.
