# 파일 이름 변경 2단계 — 2026-09-19

이 문서는 2단계 당시 기록이다. 현재 실제 실행·복구는 `FILE_RENAME_STAGE3.md`를 따른다.

실제 파일 이름은 아직 바꾸지 않는다. 실행 버튼은 비활성이다.

## 사용법과 계약

- 표의 입력 열에서 직사각형 범위를 선택해 Ctrl+C/V, Ctrl+D(첫 행을 아래로 복사), Delete, Ctrl+Z/ Ctrl+Y를 사용한다. 되돌리기/다시 실행 버튼도 있다. 셀 편집 중에는 텍스트 편집기의 기본 단축키가 동작하고, 편집 확정 후 표 Undo에 반영된다.
- 붙여넣기는 선택 왼쪽 위를 시작점으로 한다. 빈 셀·공백·001·따옴표 안의 탭/줄바꿈을 보존한다. 원본보다 큰 선택 영역에 반복 채우지 않는다. 범위를 넘거나 불균일한 행/잘못된 따옴표이면 아무것도 바꾸지 않는다. 비연속 선택과 읽기 전용 열 편집은 거부한다.
- 입력 열 하나의 원하는 행을 선택해 `현재 이름 채우기`를 누른다. 마지막 확장자만 제외한다: `archive.tar.gz` → `archive.tar`. 기존 입력을 대체하며 Undo로 복원한다.
- `목록에서 제거`는 선택한 셀이 속한 행만 목록에서 제거한다. 원본 파일은 삭제하지 않는다. 행 번호를 끌면 파일 경로와 입력값이 함께 이동한다. 둘 다 Undo 가능하다.
- 방향키·Tab으로 이동, Enter로 다음 행 이동, Shift+클릭/끌기로 범위를 선택한다. 입력은 더블클릭/F2/문자 입력으로 시작한다.
- 바뀔 이름의 추가/교체 부분은 노란색, 변경 행 미리보기는 옅은 배경으로 표시한다. 삭제된 문자는 새 이름에 없으므로 현재 이름과 비교한다. 변경/동일/건너뜀 개수를 표시한다. 미리보기를 복사할 때는 공백 표식이 아닌 실제 값이 복사된다.
- Ctrl+Z는 표 편집용이다. 파일 추가·입력 확정·구분자·열·행 작업도 복원하고 최근 100건을 유지한다. 새 편집을 하면 Redo가 비워진다. 재호출은 이력을 유지하지만 앱 재시작에는 유지하지 않는다.
- 탭/줄바꿈을 보존해도 파일 이름으로 유효하다는 뜻은 아니다. 유효성 검사·실행·실제 파일 취소는 3단계, 채우기 핸들은 4단계다.
