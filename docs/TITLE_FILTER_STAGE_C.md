# 제목 필터 G-C — 2026-09-19

## 사용자에게 보이는 변경

- 검색창 오른쪽에서 기호와 `[머리말]`을 고른다. 적용 전에는 가장 많은 값과 개수, 적용 후에는 선택값과 화살표를 표시한다. 같은 개수는 최근 수정된 값이 먼저다.
- 조건에 맞는 값이 없으면 점선 버튼을 누르면 설명이 열린다. 전체 데이터에 값이 없을 때만 제목 작성 예시를 보여준다. 확인·Esc로 닫는 비모달 팝업이다.
- 머리말 항목이 10개를 넘으면 메뉴 안에서 검색할 수 있다. 활성값은 검색 결과가 없어도 남고, 해당 메모가 0개가 되어도 선택을 유지한다.
- 더보기 왼쪽의 `↺ 필터 초기화`는 카테고리·검색·기호·머리말만 해제한다. 좁은 창에서는 `↺`만 표시한다. 보기·정렬·고정·메모 데이터와 편집 중 본문은 유지한다.

## 코드 경계

- `title_filter_controls.py`: 버튼 표시, 테스트 가능한 메뉴 생성, 도움말, 배율, 초기화. 기존 `count_title_values` 집계 순서를 그대로 쓴다.
- `memo_list.py`: 머리말/초기화 버튼 배치, 기존 필터 엔진 연결, 필요 폭에 따른 기존 콤보 반응형 처리.
- `panel.py`: 앱 배율 전달, 필터 신호를 목록만 갱신하는 함수로 연결. 편집창 재로딩과 자동 저장 유발을 피하기 위해 목록 갱신 중 신호를 차단한다. 일반 검색 입력의 기존 갱신 경로는 변경하지 않는다.
- `ui_theme.py`: 활성/빈 버튼·초기화·도움말 스타일. DB 스키마·추출 규칙·저장 본문은 변경하지 않는다.
- `test_memo_title_filters.py`: 기존 활성 0개 버튼 기대값을 개수 없는 새 표기로 변경. `test_memo_sync_categories_versions.py`의 좁은 폭 기대를 더보기 이동/검색 최소 폭 보존으로 갱신했다. 새 검사는 `test_title_filter_controls.py`에 둔다.

## 계획과의 차이 및 다음 단계

- 계획 본문은 300px 미만, 완료 체크리스트는 300px에서 초기화 아이콘만 표시하도록 적혀 있다. 체크리스트를 따라 배율을 곱한 300px **이하**에서 아이콘만 표시한다.
- G-D 전에 중간 폭에서 두 콤보와 새 버튼이 겹치지 않도록 기존 반응형 임계값을 필요한 실제 크기까지 높인다. 넓은 창의 콤보는 그대로이며, 항상 메뉴로 옮기는 G-D를 미리 구현하지 않는다.
- G-D 더보기/보기/정렬 정리 → G-E 카테고리 고정 → G-F 머리말 자동완성 → G-G 종합 확인 순서다.

## 검증 범위

- Windows Python 3.10/PyQt6, Qt offscreen, 임시 DB와 생성 데이터만 사용한다. 배율 1.0/1.25/1.5의 버튼·팝업 크기, 메뉴 검색, 0개 유지, 초기화 신호 1회와 검색 신호 0회, 정렬·보기·고정·메모 보존을 검사한다.
- 실제 메인창 위젯을 생성하는 검사에서 수동 저장 모드의 미저장 본문이 필터 선택/초기화 이후 유지되는지 확인한다.
- 실제 Windows 모니터·물리 입력·한글 IME·외부 클릭 닫기는 별도 미확인이다. offscreen 검사를 실사용 완료로 간주하지 않는다.
- EXE 재빌드·배포, 사용자 메모 DB 변경, 커밋·푸시는 수행하지 않는다.
