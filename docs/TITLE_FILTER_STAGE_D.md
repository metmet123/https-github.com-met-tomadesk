## 사용법과 범위

- 검색 줄에는 검색·기호·머리말만 둔다. 보기와 정렬은 창 너비에 관계없이 칩 줄 오른쪽 `더보기`에서 선택한다.
- 메뉴는 숨은 카테고리(있는 경우만 머리글/구분선), 보기(기본/카테고리별), 정렬(기존 5종), 카테고리 설정 순서다. 현재 값에는 체크가 붙는다.
- 숨은 카테고리를 선택하면 더보기 버튼에 이름·색·활성 테두리가 표시된다. 그 외 보기 또는 정렬이 비기본이면 파란 점과 설명 툴팁, 모두 기본이면 일반 더보기를 표시한다.
- 보기/정렬은 기존 설정 키로 저장·복원한다. `필터 초기화`는 보기/정렬을 바꾸지 않는다. 목록만 갱신하는 G-C 경로와 제목 필터 시 평평한 목록 우선 규칙을 유지한다.
- 카테고리 설정은 기존 편집기의 관리 창을 연다. 그 창의 저장/변경 알림 경로를 재사용하며, 카테고리 고정 체크 등 G-E 기능은 아직 넣지 않는다.

## 구현 경계

- `memo_list.py`: 콤보 부모/숨김 처리, resize 경로 단순화, 더보기 상태, 테스트 가능한 `_build_more_categories_menu`, `category_settings_requested`, 보기/정렬 변경 시 버튼 갱신.
- `panel.py`: 새 신호를 `editor._manage_categories`로 연결.
- `title_filter_controls.py`: 검색 줄에서 사라진 콤보 폭 계산 제거.
- 기존 콤보 객체와 `_controls_in_more=True`는 기존 코드/검사 호환을 위해 남겼다. 콤보는 레이아웃에 포함되지 않으며 넓은 창에서도 다시 표시하지 않는다. 기능 범위상 계획과 차이 없음.
- 기존 메모 DB·본문·카테고리 데이터·스키마·다른 기능은 작업 과정에서 수정하지 않는다. 테스트는 임시 DB만 사용한다. EXE 재빌드·커밋·푸시는 하지 않는다.
