# 메모 정리 로컬 분석 개선 · 2026-09-19

## 변경한 동작

- 한국어 연·월·일의 연도를 보존한다. 다다음주·지난주, 이번달·다음달, 글피·N일 뒤 등 상대 날짜를 처리한다. 월·연도 경계와 윤년을 실제 날짜 연산으로 계산한다.
- 날짜와 함께 적은 요일을 대조한다. 남은 날짜·시각 표현을 조용히 버리지 않고 확인 사항에 표시한다. 정오·자정과 기존 12시간제·24시간제를 지원한다.
- 취소·완료·보류·부정·조건·반복 표현을 확인 필요로 분류한다. 이미 체크된 목록도 새 할 일로 기본 선택하지 않는다.
- 한 줄에 여러 내용이 섞이면 확인 필요로 표시한다. 아이디어나 정보 접두사가 있어도 다른 행동이 섞였는지 먼저 검사한다. 사용자는 입력을 여러 줄로 나누어 다시 정리할 수 있다. 임의로 제목을 바꾸거나 자동으로 분리하지 않는다.
- 전화·보내기·방문·TODO·아이디어 기호 등을 지원하고 주문 번호는 행동과 구분한다.
- 종료 시각 역전·동일 시각을 분석 단계부터 표시하며 편집 시에도 검증 결과를 보여 준다. 저장 단계 검증은 유지한다.
- 원문과 별개인 비교용 문자열에서 공백·목록 기호를 정규화한다. 내용·종류·날짜·시각·분류가 같은 반영 항목은 중복 가능성을 경고하고 기본 선택에서 제외한다. 사용자가 별도 등록을 명시적으로 확인하면 허용한다. 같은 묶음의 중복도 확정 단계에서 검사한다.

## 기존 데이터

기존 원문·검토 기록과 이미 등록한 일정은 변경하지 않는다. 분석 버전을 저장하여 이전 버전에서 정리했던 원문을 다시 입력하면 새 분석 결과를 만들고 기존 기록도 보존한다. 예전의 잘못된 날짜로 이미 등록한 일정은 자동 수정하지 않으며 캘린더에서 확인해야 한다.

외부 AI 연결은 추가하지 않았다. 허용·차단 설정과 기본 차단 동작은 유지한다. 복잡하거나 지원되지 않는 표현은 확인 필요 및 직접 수정으로 처리한다.
