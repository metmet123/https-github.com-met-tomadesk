# 메모 편집 버튼 배치 개선

2026-09-19 사용자 확정: 더보기 메뉴, 목차 기본 접힘, 서식 오른쪽 기능 선택(+).

- 기본 컴팩트 편집 화면: 서식 → 기능 선택(+) → 알림 → D-Day → 단축키 → 더보기.
- +는 기존 서식 도구의 버튼 자체를 이동한다. 기존 기능 목록, 입력 규칙, 순서 설정과 단축키를 유지한다. 현재 접기/모두 접기와 같은 26×26 크기이며 서식이 접혀 있어도 보인다.
- 목차는 편집기를 새로 열 때 접혀 있다. 상단 목차 버튼으로 열고 닫으며, 목차 안의 접기 버튼으로도 닫는다. 목차와 본문은 수평 레이아웃으로 나뉘며 오늘 요약을 덮지 않는다. 공간이 부족하면 목록 접기/창 확대 안내를 제공한다.
- 목차를 연 뒤 본문 폭이 줄었다는 이유만으로 다시 닫히지 않도록 가용 폭을 본문과 목차의 공통 컨테이너에서 계산한다.
- 가져오기, 백업/복원, 버전, 템플릿, 백링크/주석, 기타 메모 설정은 더보기에서 그룹별로 찾는다. 제목 줄의 가져오기 버튼과 숨은 속성 패널의 중복 기능 버튼은 컴팩트 화면에서 제외한다. 클래식 화면은 기존 경로를 유지한다.
- 검색어로 목록을 줄이고 Enter로 첫 실행 가능 기능을 선택한다. Esc로 닫으면 더보기 버튼으로 포커스가 돌아간다. 더보기는 본문 영역 안으로 제한되며 긴 목록만 세로 스크롤한다.
- ☆/★로 고정과 해제가 가능하다. 선택은 로컬 `memo_toolbar_pins` 설정에 저장한다. 고정 기능은 속성 줄 바로 아래 한 줄에 표시하며 폭을 넘는 항목은 더보기에서 계속 접근한다. 사용 빈도에 따른 자동 재배치는 하지 않는다.
- 제목 폭과 우측 오늘 요약의 배치를 확대하지 않는다. 외부 API 연결이나 메모 데이터 변환은 추가하지 않는다.

검증: 관련 UI 테스트 67개 + 하위 사례 10개 통과. 마지막 문구 변경 후 핵심 테스트 9개 재통과. 실행 파일 자체 진단 14개 통과. 임시 데이터로 화면을 렌더링했으며 실제 사용자 메모는 테스트에 사용하지 않았다.

기존 메모 정리 2번 디자인은 채택 상태를 유지하며, 이 변경은 편집기 도구와 목차 배치에 한정된다.
