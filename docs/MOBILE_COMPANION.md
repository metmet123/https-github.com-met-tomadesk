# 토마 모바일 — Markdown 문서 편집 및 QR 연결

모바일 0.3.0 APK와 PC 토마데스크 0.1.2를 함께 사용하세요. 기존 앱을 삭제하지 않고 APK를 열어 업데이트합니다. PC는 기존 프로그램을 완전히 종료한 뒤 같은 폴더에 새 EXE를 두고 실행합니다. 기존 data 폴더·계정 설정을 삭제할 필요가 없습니다. 처음 교체할 때는 기존 메모를 저장·동기화하고 백업하세요.

## 편집

메모를 열면 문서 전체가 하나의 입력창에 나타납니다. 블록마다 대화상자를 열지 않고 여러 줄을 입력하거나 붙여넣을 수 있습니다.

- `# 제목`, `## 소제목`부터 6단계 제목
- `**굵게**`, `*기울임*`, `~~취소선~~`, 인라인 코드
- `- 목록`, `1. 순서 목록`, `- [ ] 할 일`, `- [x] 완료`
- 백틱 세 개로 감싼 코드 블록
- 파이프와 구분선으로 쓰는 Markdown 표

상단의 ‘편집 / 미리보기’를 눌러 전환합니다. 미리보기에서 # 형식 제목 옆 화살표로 해당 구역을 접고 펼칩니다. 접힘은 모바일 보기 상태이며 Markdown 원문을 바꾸지 않습니다. 체크리스트 상태는 편집 화면에서 `[ ]` / `[x]`로 바꿉니다.

입력 후 잠시 멈추면 휴대폰의 암호화 저장소에 저장하고, 화면을 벗어날 때도 저장합니다. PC 반영은 동기화 버튼으로 직접 실행합니다. 문서는 1MB, 10,000줄까지 지원합니다.
더보기(…)의 MD 내보내기는 문서 원문 그대로 저장합니다. 설정의 MD 가져오기도 원문을 유지합니다.

## 기존 PC 메모와 표·이미지

PC 메모는 Markdown으로 변환해 모바일에 제공합니다. 기존 문서의 Markdown 본문을 처음 수정하여 PC에 반영할 때 `원래 제목 · Markdown 변환 전 원본` 메모를 별도로 만듭니다. 이 사본에는 원래 HTML 서식·표·첨부 이미지가 보관됩니다. 모바일 내용으로 원본을 덮어쓰기 전에 같은 저장 작업 안에서 사본을 만듭니다.

Markdown은 임의의 글자색·복잡한 표 배치·PC 전용 블록 링크·토글 기능을 모두 동일하게 표현하지 못합니다. 변환 결과가 마음에 들지 않으면 위 원본 사본에서 확인할 수 있습니다. 이미지 첨부는 미리보기 하단에 표시합니다. 외부 웹 이미지는 자동 다운로드하지 않으며, MD 파일 단독 내보내기에는 첨부 이미지 파일이 포함되지 않습니다.

Markdown으로 만든 메모는 원문을 별도로 보관해, PC에서 본문을 바꾸지 않은 동안 공백과 문법이 동기화 후에도 유지됩니다. PC에서 본문을 수정하면 최신 PC 문서로부터 Markdown을 다시 생성하므로 표현 방식이 달라질 수 있습니다. 충돌 시에는 기존 방식대로 모바일 충돌 사본을 만들어 두 버전을 보관합니다.

PC 본문에 알림 칩이 들어 있는 메모는 Markdown 변환 시 알림 연결이 사라질 수 있습니다. 이런 메모를 휴대폰에서 편집해 동기화하면 PC 원본과 알림을 유지하고 모바일 편집 내용을 별도 충돌 사본으로 저장합니다. 알림 칩이 있는 문단은 블록 편집에서도 수정할 수 없습니다.

## PC 업데이트가 필요한 이유

PC 0.1.1 이하에는 문서 전체 Markdown 저장 기능이 없습니다. 모바일은 먼저 지원 여부를 확인하고, 구버전이면 내용을 보내지 않은 채 업데이트 안내를 표시합니다. 휴대폰의 문서는 유지되며 계속 편집할 수 있습니다.

PC 0.1.2에서 ‘휴대폰 연결 · 로그인’을 열고 연결을 시작하세요. 기존 아이디·비밀번호·인증서 지문을 사용합니다. 주소는 `https://PC의-Tailscale-IP:47831` 형식이며 PC의 ‘주소 복사’를 사용하면 됩니다. `no protocol` 오류는 https://가 빠졌는지 확인하세요.

QR 연결 기능이 포함된 새 PC/모바일 0.3.1 앱에서는 PC에서 연결을 시작하면 표시되는 QR을 휴대폰의 ‘PC QR 스캔’으로 읽을 수 있습니다. QR에는 주소와 인증서 지문만 들어 있으며, 로그인 아이디·비밀번호는 휴대폰에서 별도로 입력합니다. 처음 스캔할 때 본인 PC 화면의 QR인지 확인하세요. Google Play 서비스의 QR 스캐너를 사용할 수 없는 휴대폰에서는 기존처럼 주소와 지문을 직접 입력할 수 있습니다. 이미 메모가 저장된 휴대폰은 다른 PC의 QR을 스캔해도 기존 자료를 자동으로 다른 저장소에 합치지 않습니다. QR 기능은 소스에 구현됐으며 0.3.1 APK는 아직 빌드·배포하지 않았습니다.

이번 버전에서도 동기화는 수동이고 일정/D-Day는 조회 전용입니다. Windows EXE는 코드서명 인증서로 서명하지 않았습니다. 실제 기기/Tailscale 확인 범위는 검증결과.md를 참고하세요.
