# 모바일 0.3.0–0.3.2 / PC 0.1.2 검증 결과

2026-09-19. 아래 빌드·기기 검증은 모바일 0.3.0과 PC 0.1.2 배포본에서 수행한 결과입니다.

2026-09-29: 소스를 원격 `mobile_connection` 브랜치의 최신 PC 변경에 통합했습니다. 통합본에서 PC 자동 테스트 128개(모바일 연결·Markdown·메모 검색·제목 필터·메모 트리)가 통과했습니다. 통합본의 EXE/APK 재빌드와 실제 휴대폰 연결은 아직 검증하지 않았습니다.

2026-10-01: GitHub `main`의 `9add011`을 기반으로 실제 모바일 소스 커밋 `4ea6316`을 별도 작업본에서 병합했습니다. 본문 알림 칩이 있는 메모의 모바일 편집은 PC 원본·알림을 유지하며 충돌 사본으로 저장합니다. 기존 모바일 DB에 `inline_key` 열을 추가하기 전 업그레이드 백업을 만듭니다. 관련 PC 테스트 251개와 모바일 자체 점검이 통과했습니다. 실제 사용자 DB·휴대폰에는 아직 적용하거나 검증하지 않았고, 통합 EXE/APK도 재빌드하지 않았습니다.

2026-10-02: PC 연결 창의 QR 표시와 모바일 0.3.1 소스의 QR 스캔을 추가했습니다. QR에는 Tailscale 주소와 인증서 지문만 포함하고 기존 로그인·저장소 변경 보호를 유지합니다. PC 관련 테스트 73개와 생성 QR의 독립 판독이 통과했습니다. 이 컴퓨터에 Android SDK/JDK와 기존 APK 서명키가 확인되지 않아 새 APK 빌드·실기기 검증은 아직 수행하지 못했습니다. 실제 PC 연결 서버도 이 소스 변경만으로 자동 시작되지 않습니다.

2026-10-02 추가 검증: Android 빌드 도구를 마련하고 `0.3.1`(versionCode 4) 배포 APK를 빌드했습니다. Android 단위 테스트 8개 통과, 릴리스 APK의 v2 서명 및 패키지·버전 확인 완료. 파일은 `release/TomaMobile-0.3.1-QR.apk`입니다. 기존 0.3.0 서명키를 찾지 못해 새 서명키로 제작했으므로 기존 앱을 삭제한 뒤 설치해야 합니다. 새 키는 이 PC의 `%LOCALAPPDATA%/CodexShortcutLauncher/signing/`에 보관했습니다. QR은 PC 서버가 켜졌을 때 표시되며 주소·인증서 지문만 입력합니다. 첫 로그인에는 기존 방식대로 아이디·비밀번호가 필요합니다. 이 PC에 연결된 Android 기기가 없고 포트 47831도 열려 있지 않아 실제 휴대폰 스캔·로그인까지는 아직 검증하지 못했습니다.

PC용 QR 포함 실행파일은 `release/TomaDesk-PC-0.1.2-QR.exe`로 빌드했습니다. 해당 EXE의 격리된 자체 점검에서 QR 생성·SQLite·TLS 인증서·암호 로그인·메모 저장 등이 성공했고, PC 모바일 연결 관련 회귀 테스트 17개가 통과했습니다. 기존 PC 실행 인스턴스를 정상 종료한 뒤 새 EXE를 열고 하단 `휴대폰 연결 · 로그인`에서 계정과 연결을 설정해야 QR이 나타납니다. 실제 사용자 데이터에 연결한 동작과 휴대폰 카메라 스캔은 별도 검증이 필요합니다.

2026-10-02 PC 버튼 배치: 상단 도구를 `설명서 → 시작 → 휴지통 → 휴대폰연결 → 설정` 순서로 정리했습니다. 휴대폰연결은 설정 바로 왼쪽에 두고 동일한 도구 버튼 스타일·높이를 적용했습니다. 새 실행파일은 `release/TomaDesk-PC-0.1.2-Controls.exe`이며 UI 회귀 테스트 22개와 격리 자체 점검이 통과했습니다.
