# 변경 이력

## 2026-08-04

### 알림 메모 추가

- 메인창에 `단축키·반복작업`과 `알림 메모` 전환 화면을 추가했다.
- 메모 CRUD·검색, 메모별 단일 알림, 완료·10분 미루기, 포스트잇 고정·항상 위·색상·투명도·입력 잠금을 추가했다.
- `alert_notes.db` 분리 저장과 두 DB 통합 JSON 백업·기존 백업 호환을 추가했다.
- 넓은·좁은 화면과 독립 포스트잇 캡처를 검증하고 실제 Python 소스를 5초 실행했다.
- 범용 저장소·다중 DB 백업·Qt 창 복원 모듈을 공통 라이브러리에 반영했다.

### 변경

- 반복작업 설정을 녹화 제어·시간 설정·도움말 섹션으로 분리하고 도움말을 최하단으로 이동했다.
- 속도 방식 선택 라디오를 제거하고 속도 슬라이더를 항상 사용할 수 있도록 변경했다.
- 속도 표시 버튼을 누르면 기본 속도 1.0배로 복원되도록 변경했다.
- 매크로별 1~999회 반복 횟수 설정과 반복 실행·중지·완료 표시를 추가했다.
- 기존 녹화 시간 방식은 1.0배 속도로 자동 호환하고 과거 고정 대기 방식의 직접 실행은 유지했다.

- 기능·반응형 UI 테스트 64개 통과
- 실제 소스의 넓은·좁은 화면 캡처 확인
