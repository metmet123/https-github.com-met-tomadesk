## 2026-08-04 알림 메모 통합

- 요청: 알림노트 프로젝트의 알림과 고정 포스트잇 핵심을 단축키 프로그램의 별도 패널로 통합
- 처리: 원본을 보존하고 `alert_notes/` 패키지, `alert_notes.db`, 두 DB 통합 백업, 메인 화면 전환을 구현
- UI: 승인된 ImageGen 목업을 기준으로 넓은·좁은 화면과 포스트잇을 구현하고 인터페이스 전체 검토 `Approve`
- 검증: 신규 10건, 기존 기능 56건, 기존 반응형 UI 8건 통과 및 실제 Python 소스 5초 실행
- 재사용: 범용 저장소·다중 DB 백업·Qt 창 복원 모듈과 테스트를 공통 라이브러리에 복사
- 배포: EXE는 요청되지 않아 생성하지 않음

## 2026-08-04 반복작업 속도와 반복 횟수

- 요청: 반복작업의 시간 방식 선택과 동작 순서 안내를 제거하고, 속도 복원 버튼 및 사용자 지정 반복 횟수를 추가
- UI 결정: 녹화 제어·시간 설정·도움말로 구분하고 반복 횟수는 녹화 제어에, 도움말은 최하단에 배치
- 처리: 1~999회 반복, 0.5~10.0배 속도, 반복 중지, JSON·Excel·편집 이력 호환을 구현
- 검증: 자동 테스트 64개 통과, 실제 소스의 넓은·좁은 화면 캡처 확인
- 배포: EXE는 요청되지 않아 생성하지 않음

## 2026-08-03 제외 프로그램 단축키 전달

- 요청: 제외 프로그램에서 런처 작업 단축키가 실행되지 않을 뿐 아니라, 대상 프로그램의 자체 단축키도 동작하지 않는 문제 수정 및 EXE 생성.
- 처리: 제외 앱이 포그라운드일 때 해당 작업 단축키를 해제하고, 창 전환 시 다시 등록하도록 변경.
- 검증: 집중 단위 테스트 3건과 개별 반응형 UI 테스트 통과. 전체 Qt 묶음 테스트는 기존 offscreen 네이티브 종료로 개별 프로세스 검증을 사용. 단일 EXE는 6초 실행 상태 유지 확인 후 종료.
