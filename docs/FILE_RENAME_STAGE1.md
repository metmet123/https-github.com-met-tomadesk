# 파일 이름 일괄 변경 1단계 (2026-09-19)

이 문서는 1단계 당시 기록이다. 현재 2단계 표 편집까지 구현했으며 최신 사용법은 `FILE_RENAME_STAGE2.md`를 따른다.

## 사용법

1. 프로그램을 소스로 다시 실행한다.
2. 트레이 아이콘의 메뉴에서 `파일 이름 일괄 변경`을 열고 파일을 창으로 끌어다 놓는다.
3. 탐색기 선택을 바로 가져오려면 설정의 공통 단축키 `파일 이름 일괄 변경`을 지정한 뒤 탐색기에서 파일을 선택하고 해당 단축키를 누른다. 기본 단축키는 비어 있다.
4. 표의 1·2·3열을 입력하면 `바뀔 이름`이 즉시 갱신된다. 열은 2~5개까지 조절한다. 구분자는 빈 칸 사이에는 넣지 않고 입력한 공백과 마지막 확장자는 보존한다.

현재는 미리보기만 제공한다. 실제 파일 이름 변경과 실행 취소는 3단계에서 구현한다. 창을 닫았다 다시 열어도 이번 실행 중 입력은 유지되고, 다시 불러온 파일은 중복 추가하지 않는다.

## 검증

- 신규 집중 검사 7개 통과: 이름 조합, 공백·확장자, 파일 순서·중복·제외, 보기 순서 API 요청, 표 입력·열 제한·원본 보존, 로컬 URL 드롭, 창 재사용, 단축키 저장·해제·충돌.
- 관련 기존 검사: 단축키 안내, 창 고정, 단축키 업데이트, 설정 UX, 기능 업데이트의 137개를 확인했다. 최초 실패한 설정 항목 개수/배치 계약은 13개와 7+6 배치로 수정 후 해당 검사를 재실행해 통과했다. 신규 검사와 합쳐 중복을 제외한 144개가 통과했다. 전체 회귀는 실행하지 않았다.
- 컴파일 확인: 신규 모듈과 수정한 두 애플리케이션 모듈 통과.
- 오프스크린 배치 확인: 620×400 최소 크기 표 공간 검사 통과. 화면 캡처에서는 글꼴이 사각형으로 표시되어 한글 가독성 검증 근거로 사용하지 않았다.
- 실제 Windows 11 탐색기 탭·정렬별 선택 순서, 물리 드롭, 100/125/150% 배율 확인은 남아 있다.

탐색기 순서 구현 근거: Microsoft의 [SVGIO_FLAG_VIEWORDER 설명](https://devblogs.microsoft.com/oldnewthing/20190409-00/?p=102406). 선택 목록을 보기 순서로 요청하며 읽기 실패를 임의의 이름순 재정렬로 대신하지 않는다.
