# 파일 이름 변경 4단계 — 채우기 핸들 (2026-09-19)

소스로 프로그램을 다시 실행하면 사용할 수 있다. 기존 EXE는 변경하지 않았다. 파일 실행·검사·복구는 `FILE_RENAME_STAGE3.md`의 계약을 유지한다.

## 사용법

1. 입력 열에서 시작 셀 또는 연속된 직사각형 범위를 선택한다. 선택 범위 오른쪽 아래의 파란 사각형이 채우기 핸들이다.
2. 파란 사각형을 아래로 끈다. 채워질 범위가 점선과 옅은 색으로 표시되며, 아직 입력은 바뀌지 않는다.
3. 표 안에서 마우스를 놓으면 시작 범위 바로 아래부터 대상 행까지 한 번에 채운다. 여러 입력 열을 선택하면 열마다 독립적으로 규칙을 계산한다. 대상 칸의 기존 값은 대체한다.
4. Esc·포커스 상실·창 닫기/숨기기·표 밖에서 놓기는 취소다. 위로 끌거나 이동 없이 놓으면 아무것도 바꾸지 않는다. 한 번의 Ctrl+Z로 전체 채우기를 되돌리고 Ctrl+Y로 다시 적용한다.
5. 아래쪽 가장자리에서 잠시 유지하면 자동 스크롤한다. 새 파일 행을 만들지 않고 기존 마지막 행까지만 채운다. 마지막 적용은 표 안에서 놓을 때만 한다.

## 값 규칙

| 시작 값 | 이어 채우는 값 |
| --- | --- |
| `1` | `2`, `3`, `4` |
| `009` | `010`, `011`, `012` |
| `테스트1` | `테스트2`, `테스트3` |
| `문서-01` | `문서-02`, `문서-03` |
| `2`, `4` | `6`, `8`, `10` |
| `6`, `4` | `2`, `0`, `-2` |
| `같은 글자` | 같은 글자 반복 |
| `가`, `나` | `가`, `나` 순서 반복 |

- 앞뒤 공백·빈 칸·앞자리 0은 보존한다. 숫자가 자리 수를 넘으면 잘라내지 않는다.
- 두 개 이상 시작 값이 같은 접두/접미 문자열과 일정한 정수 간격을 가지면 그 간격을 이어간다. 세 개 이상도 같은 원칙이다. 간격이나 문자열 형식이 맞지 않으면 선택한 원문 배열을 순서대로 반복한다.
- 정수/문자열 끝의 ASCII 숫자만 추론한다. 순수 소수·쉼표 표기(`1.5`, `1,000`)는 텍스트로 반복한다. 날짜·실수 계산·알파벳 순서는 추론하지 않는다. 날짜처럼 생긴 문자열도 끝 숫자가 있으면 일반 문자열 접미 번호로 처리할 수 있으므로 미리보기를 확인한다.
- 1,024자를 넘는 셀은 과도한 숫자/정규식 계산을 피하도록 원문을 반복한다. 입력 자체를 잘라내지는 않는다. 실제 파일 이름 길이 검사는 3단계에서 별도로 적용한다.
- 부호만 있는 정수 셀은 부호를 계산에 사용하지만 `문서-01`의 하이픈은 접두 문자열이다.
- 기존 Ctrl+D는 번호 증가가 아니라 첫 행을 그대로 복사하는 기능으로 유지한다.

## 보호 범위

- 현재 이름/바뀔 이름 열, 비연속 선택, 셀 편집 중에는 핸들을 표시하지 않는다. 문제 행 필터가 켜졌거나 숨겨진 행이 있으면 핸들을 사용하지 않는다.
- 드래그 도중 행·열·값 변경이나 필터 전환이 일어나면 취소한다. 기존 파일 경로와 행 연결은 유지한다.
- 채우기는 표 입력과 미리보기만 바꾼다. 실제 파일 변경은 별도의 확인 창을 거치는 3단계 실행 버튼에서만 일어난다. 오류 이름/중복이 만들어지면 기존 검사가 실행을 막는다.
- 가로/위 방향 확장, 핸들 더블클릭 자동 채우기는 이번 범위에 없다.
