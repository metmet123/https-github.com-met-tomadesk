ROADMAP

체감 효과가 큰 순서로

우선순위는 사용 빈도·조작 절감·기존 기반 재사용을 기준으로 한 제안입니다. 측정된 사용자 통계나 확정 공수는 아닙니다.

단계완료 후 달라지는 점현재 상태진행 단위
1. 메모를 더 빨리 찾고 쓰기분류를 고정하고 머리말을 선택해 제목 작성신규 중심A → B → C
2. 설정창을 한 화면으로 정리단축키와 일정 설정을 두 열에서 직접 변경신규 중심A → B → C
3. 표의 행·열·표 전체 이동표 내용과 서식을 유지하며 순서 변경신규 중심A → B → C
4. 빠른 일정과 캘린더 실사용 마감입력·시간 해석·실제 알림을 믿고 사용검증·보완검증 → 재현 결함 수정 → 재확인
5. 창 배치와 반복 작업 도구 마감작업 창·파일·OCR 흐름을 실제 환경에서 사용검증·보완검증 → 재현 결함 수정 → 재확인
6. 메모 편집·로컬 정리의 완성도긴 메모 작성·정리·복원 흐름의 일관성검증·보완검증 → 재현 결함 수정 → 재확인
7. 안정화와 업데이트 배포확인된 변경만 업데이트로 전달품질·배포관련 회귀 → 배포 후보 검증

기능 고장·데이터 손실·반복 크래시가 재현되면 해당 수정은 순서와 무관하게 먼저 처리합니다. 기존 기능의 결함이 없으면 확인 기록만 남깁니다.

PHASE 01신규 중심

메모를 더 빨리 찾고 쓰기

매번 쓰는 카테고리와 제목 입력부터

예상 체감 · 매우 높음상대 작업 범위 · 작음~중간구현 후 해당 흐름 실사용 확인

메모를 찾고 새 제목을 쓸 때마다 효과가 생깁니다. 이미 구현된 필터 위에 남은 두 기능을 붙이므로 첫 단계 결과를 확인하기 쉽습니다.

1-A

자주 쓰는 카테고리 고정 · G-E

신규
  • 카테고리 설정에 ‘목록에 항상 보이기’ 체크를 추가합니다. 설정이 없으면 기존 순서의 앞 3개를 기본값으로 사용합니다.
  • ‘전체’는 항상 표시하고 ‘미지정’도 선택해 고정할 수 있게 합니다. 고정하지 않은 분류는 더보기에서 선택합니다.
  • 폭이 모자라면 뒤쪽 칩부터 더보기로 이동합니다. 새 분류는 자동 고정하지 않고, 삭제한 분류는 고정 목록에서도 제거합니다.
  • 순서 변경은 기존 위로/아래로 버튼을 유지하는 안을 권장합니다. Ctrl+↑/↓ 추가는 보조 경로로 검토하며 기존 버튼 제거는 확정하지 않습니다.
1-B

제목 머리말 자동완성 · G-F

신규
  • 제목 앞에서 ‘[’ 또는 ‘[토’를 입력하면 기존 머리말을 사용 빈도 기준으로 제안합니다. 빈 목록에서는 자유 입력을 유지합니다.
  • 선택한 머리말 구간만 바꾸고 제목 앞 기호와 뒤쪽 본문은 보존합니다. Enter로 선택, Esc로 닫기, Undo 한 번으로 복원합니다.
  • 한글 IME 조합 확정 Enter와 제안 선택 Enter를 구분합니다. 자동 저장과 메모 전환 중 미저장 제목도 보존합니다.
1-C

필터 통합 마감 · G-G

검증·보완
  • 이미 구현된 기호·머리말·검색·카테고리 AND 필터, 0개 결과 안내, 필터 초기화, 상시 더보기를 새 기능과 함께 확인합니다.
  • 목록·독립 창의 설정 반영, 삭제된 카테고리 복구, 설명서와 캡처를 갱신합니다. G-C/G-D는 재구현하지 않습니다.

PHASE 02신규 중심

설정창을 한 화면으로 정리

단축키와 일정 설정의 길고 복잡한 조작 줄이기

예상 체감 · 높음상대 작업 범위 · 중간구현 후 해당 흐름 실사용 확인

설정 시 변경 위치를 찾기 쉽고, 단축키를 직접 눌러 등록할 수 있습니다. 10월 1일의 기존 조밀한 설정창 계획을 구현 단위로 나눴습니다.

2-A

단축키 15개와 직접 입력

신규
  • 왼쪽 ‘메인과 메모 / 일정’, 오른쪽 ‘창과 도구 / 실행 제어’로 배치합니다. 빠른 일정·포스트잇 열기도 단축키 탭에 모읍니다.
  • 각 행은 ‘기능 이름 | 현재 조합 | ⋯’. 클릭 후 키 입력으로 변경하고 Esc·포커스 이탈·탭 전환은 미완성 입력을 취소합니다.
  • 사용 안 함·기본값 복원을 메뉴로 제공하되 녹화 종료와 실행 긴급 중지는 해제하지 않습니다. 숫자패드 표시는 읽기 쉽게 바꾸고 판정은 유지합니다.
  • 입력 중인 짧은 구간에만 기존 전역 단축키 실행을 억제하고 종료·취소 시 복원합니다. 녹화·매크로 실행 중에는 입력을 시작하지 않습니다.
2-B

일정·D-Day 2열 구성

신규
  • 왼쪽은 포스트잇 표시 대상·기본 보기·줄 수·완료 방식, 오른쪽은 D-Day 알림·표시·계산·날짜 인식으로 묶습니다.
  • 기존 보기 4종, 줄 수 3~15, 완료 방식 취소선/휴지통을 유지합니다. ‘당일 첫 실행 시 알림’처럼 실제 동작에 맞춰 문구를 교정합니다.
  • 분류 관리는 작은 버튼, 표시 예시는 기본 접힘으로 둡니다. 예시는 가상 데이터만 사용하며 휠에 의한 의도치 않은 값 변경은 막습니다.
2-C

되돌리기·저장·창 크기

신규
  • 하단은 ‘변경 상태 | 되돌리기 | 취소 | 설정 저장’. 되돌리기는 창을 열 때의 편집값, 취소는 저장 없이 닫기, 탭 전환은 미저장값 유지입니다.
  • 백업·복원·분류 관리 같은 별도 작업은 되돌리기에서 제외합니다. 문제 단축키는 기존 값 유지, 나머지 설정 저장이라는 기존 규칙을 유지합니다.
  • 내용과 글꼴로 적정 높이를 계산합니다. 기본 창에서는 내부 스크롤 없이 15항목과 저장줄을 표시하고, 작은 화면·고배율에서는 내용만 스크롤합니다.
  • 프로그램·데이터 등 다른 탭은 공통 여백과 크기 처리만 맞춥니다. 실제 파일에는 별도 작업 변경분이 있어 착수 시 겹치는 부분을 재확인합니다.

PHASE 03신규 중심

표의 행·열·표 전체 이동

문서를 다시 입력하지 않고 순서 바꾸기

예상 체감 · 높음상대 작업 범위 · 중간~큼구현 후 해당 흐름 실사용 확인

표를 자주 쓰는 메모에서 반복 편집을 크게 줄입니다. 내용·이미지·병합 셀 보존 부담이 있어 행·열과 표 전체를 작은 단계로 나눕니다.

3-A

표 A/B 기반 확인

검증·보완
  • 행·열 삽입/삭제, 폭 조절, Excel 범위 붙여넣기, 서식·병합/분할은 구현되어 있습니다. 표 C와 맞닿는 데이터·Undo 경로를 먼저 확인합니다.
  • 병합 셀을 가로지르는 이동은 첫 버전에서 차단하고 이유를 표시하는 안을 권장합니다. 병합을 유지한 복잡한 재배열은 지원 규칙을 따로 정한 뒤 확장합니다.
3-B

행·열 드래그 이동

신규
  • 손잡이로 이동 대상을 구분하고 놓일 위치에 삽입선을 표시합니다. 클릭·셀 선택·열 너비 조절과 드래그 시작 조건을 분리합니다.
  • 드롭 성공 전 원본은 유지합니다. Esc·영역 밖 놓기는 취소하고 하나의 이동을 Undo/Redo 한 단계로 묶습니다.
  • 같은 명령을 우클릭의 위/아래·왼쪽/오른쪽 이동으로도 호출하는 안을 제안합니다. 키보드만으로 순서를 바꿀 수 있게 합니다.
3-C

표 전체 이동

신규
  • 표를 같은 메모의 문단 사이로 이동합니다. 접힌 제목·토글의 숨은 내부로 들어가지 않도록 목적지를 명확히 표시합니다.
  • 셀 내용·서식·이미지 참조·블록 ID·링크·접힘 경계와 저장·재열기·백업 왕복을 확인합니다.
  • 다른 메모로 드래그, 드래그 복제, 자유 좌표 배치는 이번 단계에서 확장하지 않습니다.

PHASE 04검증·보완

빠른 일정과 캘린더 실사용 마감

새 기능은 적지만 입력 실수와 불확실성을 줄이는 효과가 큽니다. 현재 팝오버·시간축의 사용감을 실제 환경에서 확인하고 재현된 결함을 수정합니다.

4-A

DELIVERY RULES

한 단계씩 구현하고 확인하는 방식

  1. 착수: 해당 단계의 현재 코드·기존 변경·시안을 대조해 범위를 고정합니다. 문서의 옛 상태를 구현 사실로 가정하지 않습니다.
  2. 구현: A/B/C 중 한 단위를 끝내고 관련 자동 검사·저장 왕복을 수행합니다. 실제 고장이 재현되면 원인과 수정 범위를 기록합니다.
  3. UI 확인: 시안과 실제 캡처, 폭 3종 × 100/125/150%, 클릭·키보드·IME를 대조합니다. 기본 조작 영역의 잘림과 불필요한 가로 스크롤은 0을 목표로 합니다.
  4. 단계 보고: 변경 파일, 동작 결과, 테스트 결과, 실제 확인과 미확인, 남은 선택 사항을 함께 보고합니다. 다음 단계 진행은 사용자의 단계별 지시에 따릅니다.
  5. 배포: 배포 요청 시 대상 변경을 확정하고 누적 회귀·EXE·백업 복구를 확인합니다. 구현 완료와 배포 완료를 각각 기록합니다.

UI 원칙: 기존 UI 디자인 지침의 줄·폭 예산, 기존 줄에 진입점 통합, 토글 위치 고정, 같은 서랍 한 번에 하나, 실제 창 확인 기준을 반영했습니다. 앞뒤 비교는 실제 측정 캡처가 아닌 구조 설명 목업입니다.
